# MusicStats

**Purpose:** Parse .xml files provided by Winamp to create my music library's statistics.

**IDE:** Qt 6.

**Details:** I'm a fan of offline music listening, with complete, obsessive control over my music library (a consistent approach to naming, choosing my favorite album versions, and other advantages that streaming services doesn't offer). I've been using Winamp for this my whole life, and I've yet to find another player that even comes close to its ease of use. The only problem is that I'm also a fan of statistics, and Winamp only provides play counters for individual tracks, and nothing more. This project works with .xml files that Winamp can create to display everything it can glean in a simple and visual way — player statistics for each band, album, and track, graphs of distribution by plays, years, and genres, graphs of changes in my music library over time, and much more.

**Usage:** In Winamp choose "Library->Export multimedia database". In MusicStats choose one .xml file for statistics on the current state of the library, or two .xml files for statistics for the period between these files, or several .xml files to visualize changes in the library over a long period of time.
